# Binhua (Ben) Liang — Research Portfolio

Static professional research portfolio for Binhua (Ben) Liang, MD, MSc, PhD.

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `binhua-liang`.
2. Upload `index.html` and the `assets/` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The site will be available at:
`https://<your-github-username>.github.io/binhua-liang/`
